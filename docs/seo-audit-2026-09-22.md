# SEO audit: bhgforklifttraining.com (2026-09-22)

## Scope and sources

Google Drive has **no SEO audit for this site**. The closest documents are:

- **SEO Audit — BHG Safety Partners** (Sept 13, 2026): 16 findings on bhgsafety.com.
- **BHG Siblings — Baseline Evidence & Limitations** (Sept 22, 2026). It says this site is "frozen at bhgsafety.com's pre-September state," with none of the parent audit's fixes ported.

This audit therefore checks each of the parent audit's 16 findings against this repo and the live site. It also adds findings that apply only to this site.

It was checked against:

- **The repo:** `main` at `1f168ee`, built with `next build`, 1,638 prerendered pages. A script checked the prerendered HTML.
- **The live site:** `https://www.bhgforklifttraining.com`, fetched on 2026-09-22. The apex domain 308-redirects to `www`, so `www` is the live host.
- **DataForSEO:** `ranked_keywords` and `backlinks_summary` for the domain, pulled on 2026-09-22.

Status key:

- **Open:** still a problem, and fixable in this repo.
- **Fixed:** already correct.
- **Off-site:** needs work outside the code (Google Business Profile, backlinks, DNS, or a business decision).

## Strategic context: read this first

The Sept 22 baseline records a **forklift disposition analysis**. It recommended **Option A**: fold this domain into bhgsafety.com and 301-redirect the class pages page-for-page. The reasoning:

- bhgsafety.com already holds Maps position 1 for "forklift training near me" and "forklift training".
- It now also has its own `/services/forklift-operator-certification` page.

**Option B** (keep this domain and differentiate it) was judged defensible only if forklift certification is run as a separate brand. That would mean its own analytics, Search Console, business profile and link program.

Bringing this site "up to the same standard" as bhgsafety.com is Option B. That choice decides most of the findings below, especially S2, S3 and #14. **It needs a decision before the structural work.**

## Findings that apply only to this site

| # | Finding | Status |
|---|---|---|
| S1 | **Class pages are orphaned from the sitemap and have no hub.** The seven `/classes/class-N-forklift` pages are the only unique content and the only pages ranking for forklift terms. The sitemap omits them, `/classes` returns 404, and the only links to them are the home page cards. | Open |
| S2 | **Cross-domain duplicate content.** All 6 `/services/*` pages have the same `longDescription` as bhgsafety.com's pages of the same slug. `data/locations.json` and all city/state copy are also the same. Google will pick one version to index, and it is unlikely to be this domain's. | Open; **needs a decision** |
| S3 | **Wrong brand in titles and schema.** Every `<title>`, the `Organization` and `LocalBusiness` schema, the logo alt text, the footer copyright and `llms.txt` say "BHG Safety Partners", and `llms.txt` describes a safety-consulting firm. The hero and the contact-form sender say "BHG Forklift Training". | Open; the name depends on the Option A/B decision |
| S4 | **Broken links on every page.** The footer links to 5 service pages that don't exist (`/services/safety-training`, `/osha-compliance`, `/hazard-assessments`, `/safety-audits`, `/emergency-response`) and to `/privacy` and `/terms`, which both 404. That is 7 broken links on all 1,638 pages. | Open |
| S5 | **No privacy policy or terms**, although the site collects form data (sent through Resend) and is hosted on Vercel. | Open |
| S6 | **No analytics.** There is no GA4 tag or conversion event, so there is no traffic history to recover. | Open; needs a GA4 property ID |
| S7 | **Placeholder social links.** The header icons link to the bare `facebook.com`, `twitter.com`, `youtube.com` and `instagram.com` home pages. `Organization.sameAs` lists `facebook.com/bhgsafetypartners` and `linkedin.com/company/bhg-safety-partners`, neither of which has been verified. | Open |
| S8 | **Class-page claims need checking.** All seven class pages share one hard-coded curriculum and the same "4 to 6 hours" duration, and state "Must be 18 years or older." OSHA's 18+ rule (29 CFR 570.58, Hazardous Occupations Order 7) applies to non-agricultural employment, so the claim is broadly right. The class names match OSHA's seven powered-industrial-truck classes. | Duration confirmed by BHG on 2026-09-23. Company stats also confirmed (31,000+ operators, 5,000+ companies, 65+ years; the site said 45+ and was corrected) |
| S9 | **The sitemap uses build-time `lastModified`** on every URL, so every deploy tells Google every page changed. | Open |
| S10 | **There is one blog post**, which is not in the nav and is about general onsite safety training, not forklifts. | Open |

## Off-site summary

1. **No Google Business Profile for this domain.** Decide first whether it should have one. A second profile at the same Hannibal address as BHG Safety Partners risks a duplicate-listing suspension. The baseline also warns against starting a citation audit until the parent address conflict is resolved.
2. **Backlinks:** 19 spammy domains from the same batch as bhgsafety.com's. Do a disavow review once for all three domains.
3. **Search Console:** submit the sitemap after the sitemap PR merges.
4. **Email:** `bhgforklifttraining.com` has no MX records. Either use an address on another domain or set up mail on this one.
